Как установить

Android

Нажми «Скачать для Android», открой скачанный файл PlayLek.apk. Если телефон спросит, разреши установку из этого источника (браузера или менеджера файлов) и нажми «Установить». Если видишь «ошибка при анализе пакета», скачай файл ещё раз через Chrome: обычно файл просто не докачался.

Windows

Нажми «Скачать для Windows», запусти установщик .msi. Если Windows покажет синее окно SmartScreen, нажми «Подробнее», потом «Выполнить в любом случае». Версию из ZIP можно просто распаковать и запустить PlayLek.exe.

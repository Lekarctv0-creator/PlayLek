Установка導入

01

Android

Скачай APK и открой файл. Разреши установку из этого источника и нажми «Установить». Если пишет «ошибка при анализе пакета», скачай файл ещё раз через Chrome: он, скорее всего, не докачался.

02

Windows

Запусти .msi. Если Windows покажет синее окно SmartScreen, нажми «Подробнее», затем «Выполнить в любом случае». ZIP достаточно распаковать и запустить PlayLek.exe.

03

Обновления

Новые версии приложение предложит скачать само. Эта страница всегда отдаёт самую свежую.
